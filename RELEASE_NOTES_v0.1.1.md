# scDesignGuard v0.1.1

v0.1.1 is a reproducibility-packaging release for the evaluated NM03 v0.1.0
software.

It adds four terminal-state fixtures with golden outputs, archive-relative
tests, a 17-method source suite, four clean-environment wheel fixture checks,
bounded integrity receipts and synchronized manuscript artifacts. The release
archive is checksum-bound by `RELEASE_ASSET_CHECKSUMS_v0.1.1.sha256`.

Evaluator source, schema version 1.0.0, 21-code reason registry, wheel and OCI
identity are unchanged from v0.1.0.
