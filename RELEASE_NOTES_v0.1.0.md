# scDesignGuard v0.1.0

First public research-software and reproducibility release.

## Included

- deterministic design-contract compiler and four-state validity gate;
- 21 machine-readable reason codes and JSON Schema v1.0.0;
- exact evaluated wheel, source modules, synthetic fixture and tests;
- API, installation, security and reproducibility documentation;
- project-generated manuscript, Supplementary Information, Source Data and
  publication figures;
- portable aggregate Source Data reconciliation script.

  evaluated archival bundle, including the OCI archive.
- `scdesignguard_nm03_0.1.0.oci.tar` is the exact evaluated OCI archive for
