# Contributing

We welcome reproducible bug reports, tests and narrowly scoped pull requests.

1. Open an issue describing the observed behavior, exact software version,
   operating system and a minimal synthetic example.
2. Do not upload controlled data, identifiable participant information,
   credentials, repository cookies or material whose redistribution rights are
   unclear.
3. Preserve fail-closed behavior. Changes that alter terminal-state priority,
   schema semantics, reason-code definitions or authorization boundaries must
   be proposed as a new version and accompanied by tests and a migration note.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
